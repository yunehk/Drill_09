# Drill #9: 소년 상하좌우 이동

`move_character_with_key.py`를 실행합니다.

```text
python move_character_with_key.py
```

- 방향키: 상하좌우 이동 (동시에 누르면 대각선 이동)
- 키를 놓으면 대기 애니메이션으로 전환
- 위아래 이동 시 마지막 좌우 방향 유지
- Esc 또는 창 닫기: 종료

Python과 pico2d가 필요합니다. 필요한 경우 `python -m pip install pico2d`로 설치합니다.
이미지는 코드 파일을 기준으로 불러오므로 다른 폴더에서 실행해도 됩니다.
